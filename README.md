# บันทึกรายจ่าย (Expense Tracker)

แอปบันทึกรายจ่ายแบบไฟล์เดียว (HTML + CSS + JS) ไม่ต้องติดตั้งอะไรเพิ่ม
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์

## หมวดหมู่
ค่าอาหารหลัก · ค่าซื้อขนม · ของใช้ทั่วไปที่จำเป็น · ของเล่น/Fulfill ตัวเอง · ค่าที่พัก · ค่าใช้จ่ายสำหรับพ่อแม่ · ของขวัญ · อื่นๆ (ระบุเอง)

## ใช้งาน
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย

## เผยแพร่ด้วย GitHub Pages
1. อัปโหลด `index.html` และ `README.md` ขึ้น repository
2. ไปที่ Settings → Pages
3. เลือก Source เป็น "Deploy from a branch" แล้วเลือก branch `main` โฟลเดอร์ `/ (root)`
4. รอสักครู่ จะได้ลิงก์ `https://<username>.github.io/<repo-name>/`
